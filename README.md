Weather Pipeline



A weather analytics pipeline using Python, Open-Meteo API, Google BigQuery, SQL, and Looker Studio.



Project Overview



\* Fetch current weather data from Open-Meteo.

\* Process and clean data using Pandas.

\* Combine weather and population data.

\* Calculate temperature in Fahrenheit and categorize temperatures.

\* Store processed data in Google BigQuery.

\* Analyze weather data using SQL.

\* Visualize insights in Looker Studio.



Technologies Used



Python, Pandas, Open-Meteo API, Google BigQuery, SQL, Looker Studio, Git, and GitHub.



BigQuery



\* Dataset: global\_weather\_data

\* Table: current\_weather\_stats

\* View: vw\_hottest\_large\_countries
